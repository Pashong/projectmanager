This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 20.0.5.

## Proman

Proman is a full-stack project management application designed to organize projects, tasks, and team members in one place. Users can create and manage projects, assign tasks to team members, and track project progress through a clear and intuitive dashboard.

The application was built with Angular and TypeScript for the frontend, Node.js and Express for the backend, and PostgreSQL for data management. It also includes user authentication and project-based access to tasks and team members.
